Part 1 · Memory

The 4 GB limit

The game is a 32-bit program. A 32-bit program can only use 4 GB of memory, even if your PC has much more.

Everything the game needs must fit in those 4 GB: the game itself, textures, models, sounds and the graphics driver. Big mods like RobZ use most of it.

When the game asks for more memory and there is no free space left, it crashes with Failed to allocate memory (eMemory.cpp, 94).

What is inside the 4 GB during a RobZ multiplayer match (with the patch)

Each square is 16 MB. There are 256 squares = 4,096 MB.

The graphics driver part is this big only on our test computer (a virtual machine). On a normal graphics card most of it is in the card's own memory. The reserve is space the patch keeps free for emergencies.

Part 1 · Memory

Moving unused data out of the 4 GB

Your PC has more memory than the game can use. Windows lets a program store data in that extra memory, but the program cannot read it directly from there.

When some game data has not been used for a while, the patch copies it into the extra memory and frees the space it took inside the 4 GB. When the game needs that data again, the patch copies it back first.

Part 1 · Memory

Freeing memory left over after a restart

When you restart a mission, the game does not free all the memory of the last round. Some of it is never used again. After a few restarts there is less free memory, and the game crashes sooner.

The patch finds that leftover data and frees it when the next map loads. It also stores small pieces of data tightly, so there are fewer unusable gaps between them.

Part 2 · Style v1

Style v1 (battle simulation)

In every step of a battle, each soldier checks which enemies he can see, where he can take cover and whether he can hit his target. With more soldiers, each soldier has more to check. So the work grows much faster than the number of soldiers, and big battles get slow.

Style v1 is a new way to make these decisions. Soldiers on the same team and in the same small area share the work: what one area can see is worked out once, and every soldier there uses it. The game's own animations, weapons, bullets and damage are not changed.

Style v1 is still in development. In multiplayer it is only used when every player in the match has version 1.0.7; otherwise the game plays as normal.
