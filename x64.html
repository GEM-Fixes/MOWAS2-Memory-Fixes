How it works 64-bit Documentation

The 64-bit build

A 64-bit version of Men of War: Assault Squad 2 (game version 3.262). Version 1.0.0. It has no 4 GB memory limit, it is compatible with the normal, unpatched game in multiplayer, and it has the same turbo mode as the 32-bit patch. You get it through the launcher. It only works if you own the game on Steam.

What it is

A 64-bit version of the game

The original game is a 32-bit program. It can only use 4 GB of memory, however much memory your PC has. Big mods use most of those 4 GB, and the game crashes when they run out.

The 64-bit build is a new game program, built from a source-code reconstruction of the game. It does not patch the original 32-bit program. A 64-bit program has no 4 GB ceiling, so the memory limit is gone.

It uses the same game files and the same mods. You need your own Steam copy of the game (see "Install and uninstall").

The memory problem

Did the game need 64-bit?

For years the community said the same thing: big mods crash with "Failed to allocate memory", and the only real fix would be a 64-bit version of the game. The crash is real and the cause is right: a 32-bit program can only use 4 GB of memory, and big mods fill it.

But 64-bit is not the only way out. The 32-bit patch keeps the game inside its 4 GB: it moves data the game is not using right now (textures, models, sounds, animations) out of those 4 GB, into your PC's normal memory, and brings it back when the game needs it. It also stops memory from piling up from one match to the next. With the patch, we know of no mod that cannot be played.

The 64-bit build removes the 4 GB ceiling itself, so none of that moving around is needed. Both solve the memory problem. You can use either one.

Speed

Speed and turbo mode

64-bit alone does not make big battles faster. They are slow because of the battle simulation, the work every soldier does to find enemies, cover and targets, and 64-bit gives more memory, not less of that work.

The 64-bit build has the same exact speed fixes as the 32-bit patch: the slowest parts of the simulation were rewritten to give the same results with less work. With the 32-bit patch they need about 1.5 to 1.7 times less simulation time than the unmodified game in a 300-vs-300 soldier test battle, and less in smaller battles.

The real speed-up: turbo mode (Style v1)

To make big battles much faster, the simulation itself has to do less work. That is what turbo mode (Style v1) does. It redesigns how soldiers sense, aim and plan, so that the work grows with the size of the battle instead of exploding with it. The fights look and play like the normal game. In our test battles the turbo mode of the 32-bit patch needed about 5.6 to 9.9 times less simulation time than the unmodified game, more the bigger the battle.

Turbo mode 1.0.0 is in the 64-bit build too, and it runs the same way as in the 32-bit patch: we played recorded real turbo multiplayer matches (Iwo Jima, Kansas, Grand Suburb, Okinawa with the RobZ Realism Mod, and Abbad Big with the Cold War mod) on the 64-bit build, and it played them just like the PC that recorded them. Its turbo speed is the same as the 32-bit turbo, within a few percent. Turbo is only used in multiplayer when every player in the match has it (see "Playing with others").

Install

Install and uninstall

You get the 64-bit build only through the launcher (MoWAS2-Launcher.exe). It is not on GitHub and there is no separate download. You do not reinstall the game. In the launcher, the Game to start box has:

  • two choices, 32-bit game with the fix and 64-bit build, each with its version;
  • the button Install 64-bit next to them. Installing selects the 64-bit build;
  • the big Play button below says which game it starts: Play (32-bit) or Play (64-bit).

Install 64-bit downloads the 64-bit build, checks it against the signed update list, and places it in the game folder next to mowas_2.exe. Uninstall 64-bit removes it again. The 32-bit patch is not touched.

Both can stay installed. Pick one in Game to start to switch between them. Always start the game with the launcher.

You need the original game. The 64-bit build only starts when it sits in the game's Steam folder next to the Steam mowas_2.exe and the game's files, Steam is running, the game's Steam file is Valve's original, and your Steam account owns Men of War: Assault Squad 2 and has it installed. Otherwise it shows a message, for example "Start Steam first" or "This Steam account does not own Men of War: Assault Squad 2 (or it is not installed).", and closes. The launcher installs it only into a Steam installation of the game.

Multiplayer

Playing with others

The 64-bit build is compatible with unpatched versions of the game: players with the 64-bit build or the 32-bit patch can play multiplayer together with players who run the normal, unpatched game. Such a match plays in vanilla compatibility mode. Real Steam matches with 64-bit and 32-bit players together have been played without out-of-sync errors.

Turbo mode

Turbo mode is on when every player in the match has a version with it: the 32-bit patch 1.0.7-rev2 or the 64-bit build 1.0.0. They play turbo together, whoever hosts. Otherwise the match plays in vanilla compatibility mode, automatically.

  • A player still on 1.0.7-rev1 needs the update, or the match may play in vanilla compatibility mode. The launcher updates automatically.
  • Stay in the lobby for about 15 seconds before the host starts the match.
  • When the match is on screen, a chat line tells you the mode, for example "64-bit build: everyone in this match runs turbo mode 1.0.0 - turbo mode is on." (32-bit players see "Memory Optimizer Patch: ..."). Otherwise it says that the match is running in vanilla compatibility mode.
  • Single player in the 64-bit build plays vanilla (no turbo).

Questions

Questions and answers

Do I need to reinstall the game?

No. Use the launcher: Install 64-bit adds the 64-bit build to the game folder, and the Game to start box chooses which game Play starts. See "Install and uninstall".

Where can I download it?

Only in the launcher: click Install 64-bit in its Game to start box. The 64-bit build is not on GitHub and there is no separate download.

Can I run it without the original game?

No. The 64-bit build only runs together with your own Steam copy of the game: in the game's Steam folder next to mowas_2.exe, with Steam running and a Steam account that owns the game and has it installed.

Is the 64-bit build faster?

64-bit alone is not. What makes big battles much faster is turbo mode (Style v1), which the 64-bit build has just like the 32-bit patch. It is used in multiplayer when every player in the match has it. See "Speed and turbo mode".

Which one should I use?

Both fix the memory crashes, and both have turbo mode. The 32-bit patch plays every mod we know of. Use the 64-bit build if you want no memory ceiling at all. You can keep both and switch in the launcher.

Does it replace the 32-bit patch?

No. Both can stay installed and you choose in the launcher. The 32-bit patch keeps being maintained.

Can I play with friends who have the normal game?

Yes. The 64-bit build is compatible with the normal, unpatched game: you play together in vanilla compatibility mode. Turbo mode is only on when everyone in the match has it. See "Playing with others".

Will my saves work?

Yes, in both directions. The 64-bit build loads single-player saves made by the 32-bit game, and the 32-bit game loads saves made by the 64-bit build, so you can switch back and forth. A save needs the same mods active as when it was made.
