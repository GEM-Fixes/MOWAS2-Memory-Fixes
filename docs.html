Install and uninstall

With the launcher (recommended)

  1. Close the game.
  2. Download the launcher zip from the releases page on GitHub.
  3. Unzip it. (Right-click it, then choose Extract All.)
  4. Open the new folder and double-click MoWAS2-Launcher.
  5. Click Yes, then click Play.

The game starts with the patch. Next time, double-click the MoWAS2 Memory Fix icon on your desktop and click Play. Always start the game with the launcher.

If Windows shows a warning: it does not know the program yet. Click More info, then Run anyway.

Without the launcher

  1. Close the game and unzip the download. You only need the file xvidcore.dll.
  2. Open the game folder, the one that contains mowas_2.exe. On Steam: right-click the game, then Manage > Browse local files. For GOG or other copies, open the folder you installed the game into.
  3. Rename the game's own xvidcore.dll to xvidcore_orig.dll. The patch needs this file: do not delete it.
  4. Copy the new xvidcore.dll into the game folder and start the game as usual.

To update by hand: copy only the new xvidcore.dll over the old one. Do not rename anything again. After a manual install you are responsible for updates and for sending crash reports yourself.

Uninstall

  • Launcher: if the 64-bit build is installed, click Uninstall 64-bit. Then open Tools, click Remove the fix, then Uninstall launcher (also in Tools). The game is back to how it was.
  • By hand: delete xvidcore.dll, then rename xvidcore_orig.dll back to xvidcore.dll.
  • On Steam, Properties > Installed Files > Verify integrity of game files also restores the original file.

The patch does not change any game files. It keeps a few small files of its own in a memhook folder inside the game folder. You can delete them at any time; they are made again.

64-bit build

The 64-bit build (version 1.0.0) is a separate game program that runs the same game files and mods without the 4 GB memory limit. It has the same turbo mode as the 32-bit patch. You get it only through the launcher: it is not on GitHub and there is no separate download. See the 64-bit page for what it is and how it differs from the patch.

What you need

You need the original game. The 64-bit build only starts when all of this is true:

  • it sits in the game's Steam folder next to the Steam mowas_2.exe and the game's files;
  • Steam is running;
  • the game's Steam file is Valve's original;
  • your Steam account owns Men of War: Assault Squad 2 and has it installed.

Otherwise it shows a message and closes, for example "Start Steam first: ..." or "This Steam account does not own Men of War: Assault Squad 2 (or it is not installed). The 64-bit build only runs together with your own copy of the game." The launcher installs it only into a Steam installation of the game.

Install

  1. Open the launcher (MoWAS2-Launcher.exe). The Game to start box has two choices: 32-bit game with the fix and 64-bit build, each with its version.
  2. Click Install 64-bit next to it.
  3. Click Play (64-bit).

Uninstall

Click Uninstall 64-bit. This removes only the 64-bit build. The 32-bit patch and your game files are not touched.

Switching between 32-bit and 64-bit

Both can stay installed. Choose one in Game to start. The Play button shows which one it starts: Play (32-bit) or Play (64-bit).

Multiplayer

The 64-bit build is compatible with unpatched versions of the game: 64-bit players can play multiplayer with players of the 32-bit patch and with players who run the normal, unpatched game. Turbo mode is only on when everyone in the match has it. See Multiplayer compatibility.

32-bit patch or 64-bit build?

Both fix the memory crashes: the patch keeps unused data outside the 4 GB, the 64-bit build has no 4 GB limit. With the patch we know of no mod that cannot be played. Both have the same speed fixes and the same turbo mode 1.0.0. 64-bit alone does not make battles faster. More on the 64-bit page.

Update channels

With the launcher you do not need to do anything to update: click Play and you get the newest version of your channel.

ChannelVersionWhat it is
Stable1.0.7-rev2The normal version, stable since 18 November 2026. Memory fixes, faster loading, a faster simulation with exactly the same results as the unmodified game, and turbo mode 1.0.0 for multiplayer matches in which every player has it.
Pre-releasetest versionsTest versions of the next update, before they become stable.

To change the channel, pick Stable version or the pre-release in the channel box next to the updates line, then click Check for updates. To go back, pick Stable version again. The 64-bit build has its own version (1.0.0); the launcher keeps it up to date as well.

The launcher window

The launcher (version 1.0.31) is called "Men of War: Assault Squad 2 - Memory Fix". From top to bottom it shows:

  • Game folder: the game the launcher works on.
  • Game to start: 32-bit game with the fix or 64-bit build, each with its version, and the Install 64-bit button (Uninstall 64-bit once it is installed).
  • Updates: the update status, the channel box (Stable version or pre-release) and Check for updates.
  • Play: the big button. It says which game it starts, for example Play (32-bit) or Play (64-bit).
  • Tools: a menu with the things you rarely need, such as the game folder, installing or repairing the fix, Remove the fix, crash reports, the project page and Uninstall launcher.
  • A log of what the launcher is doing, a Send feedback box for a short message to the developers, a language box (English, Русский, Español, Deutsch, 中文), and the buttons Join Discord and Support on Ko-fi.

Multiplayer compatibility

  • Compatible with the unpatched game. Players with the 32-bit patch or the 64-bit build can play multiplayer together with players who run the normal, unpatched game. The match then plays in vanilla compatibility mode.
  • Turbo mode. Turbo mode is on when every player in the match has a version with it: the 32-bit patch 1.0.7-rev2 or the 64-bit build 1.0.0. They play turbo together, whoever hosts. Otherwise the match plays in vanilla compatibility mode, automatically. A player still on 1.0.7-rev1 needs the update (the launcher updates automatically).
  • Before the start. Stay in the lobby for about 15 seconds before the host starts the match.
  • Chat line. When the match is on screen, the chat tells you the mode, for example "Memory Optimizer Patch: everyone in this match runs turbo mode 1.0.0 - turbo mode is on." (64-bit players see "64-bit build: ..."). Otherwise it says that the match is running in vanilla compatibility mode.

For the 64-bit build, see the 64-bit build section and the 64-bit page.

Crash and out-of-sync reports

What the launcher sends

  • An anonymous usage count once a day.
  • Out-of-sync reports and crash records, automatically.
  • Replays of finished matches for AI training, with player names and Steam IDs removed.

You can turn each of them off: click Settings... next to the language box and untick its box.

If something goes wrong, open Tools in the launcher and click Send report. That sends the crash files to the developer. You can also write a short message in the Send feedback box.

Where the files are

Crash files are in Documents\My Games\men of war - assault squad 2\log (folders minidumps and oos). When a match goes out of sync, the patch writes a full report of the match state to log\oos\full <date time> q... p....txt. Every player with the patch gets their own file. The host's file and an out-of-sync player's file are the most useful pair.

Without the launcher, send the file zipped together with game.log (in the log folder), and say which mods you run and on which map it happened.

Troubleshooting

Always include game.log, your mod list and the map when you report a problem.

Out of memory: "Failed to allocate memory ... (eMemory.cpp, 94)"

The game has run out of its 4 GB. This is what the patch is for. Check that the patch is installed (the patch version is shown in the crash dialog and in the menu), update to the newest version, and close other programs. If it still happens, send the crash files and say which mods you run. The game's memory use depends on the mod and the map. The 64-bit build has no 4 GB limit.

A mod's script failed

The mod is broken or does not fit your game version or the other mods you have active. Switch off mods you do not need, make sure the mod is up to date and was installed completely, and try again. The patch does not change mod scripts.

A file is missing: "File not found - resource/..."

The game or a mod asks for a file that is not there. Reinstall or re-download the mod; on Steam, use Verify integrity of game files. If the error appears only with the patch, send the report: the patch shares identical files between a mod's archives, and a mistake there can look like this.

The graphics card stopped working, or the screen mode is wrong

Windows can reset the graphics driver, and then the game loses its graphics device and closes. Update your graphics driver and try windowed mode or a lower resolution. Changing the display resolution while a match is running can crash the game.

"Failed to create memory mapped file (eSteamCloud.cpp, 203)" and OneDrive

The game could not write its profile copy into Documents\My Games. This is not caused by the patch. It is known to happen when the Documents folder is inside OneDrive. The patch adds a note to the crash dialog in that case. Try: set the My Games folder to "Always keep on this device", pause OneDrive, or stop OneDrive from backing up Documents. Also check for Controlled folder access, antivirus, read-only profile files, or a leftover game process.

Windows shows a warning when starting the launcher

This is normal for a program Windows does not know yet. Click More info, then Run anyway.

FAQ

Does it work with all mods?

Yes, that is the aim. Problems with a particular mod are welcome as reports.

Does it change my game files?

No. It is a single DLL that the game loads by itself. The only file it replaces is xvidcore.dll, and your original is kept as xvidcore_orig.dll.

Can I play with people who do not have the patch?

Yes. See Multiplayer compatibility above.

Do I have to use the launcher?

For the 64-bit build, yes: you get it only through the launcher. For the 32-bit patch it is recommended: it updates the patch and sends reports. Without it you update and report by hand.

Is the game still 32-bit with the patch?

Yes. The patch works inside the 4 GB limit. A separate 64-bit build is available without this limit. Both fix the memory crashes.

Will the 64-bit build make big battles faster?

64-bit alone does not. What makes big battles much faster is turbo mode (Style v1), which both the 32-bit patch and the 64-bit build have. It is used in multiplayer when every player in the match has it. See the 64-bit page.
