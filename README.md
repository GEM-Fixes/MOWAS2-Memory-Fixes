# MOWAS2-Memory-Fix
Reworks the memory handler to close out memory leaks and reduce overall load. Works with any current executable, including those without the fixes and every modification.

Ask for validation to receive the password.



HOW TO INSTALL
Close game
Unzip with Winrar or 7Zip
Run install BAT
Press anykey when prompted
Play

Windows 11 Users Follow the Below
1. Press the Windows Key and open Settings (or press Windows Key + I).
2. Click on Privacy & security in the left sidebar.
3. Click on Windows Security.
4. Select App & browser control.
5. Click on Smart App Control settings.
6. Choose Off to disable the feature and confirm when prompted.




DO NOT REDISTRIBUTE
